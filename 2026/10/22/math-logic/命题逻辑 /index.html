命题逻辑

命题

我们基于最基本的真假的概念定义了命题。为了避免自然语言的模糊和歧义我们定义了形式语言这样一种形式,即满足一定规则的符号的组合, 同过定义一个翻译的“规则”,我们实现了形式语言到自然语言的转换

其基本符号包括合取, 析取, 命题符号等等, 这些符号的组合,我们称之为表达式, 进一步地,我们只关注这些组合(符号串)中规则正确的部分,称之为合式公式,即通过对命题符号有限次运用构造公式

但是合式公式本身依然只是无意义的符号串, 为了构建其与真实逻辑的关联,我们定义了真值指派(二值逻辑), 用以定义逻辑联结符和真实逻辑关系的对应.

v : S → {T, F} 即对于每一个命题逻辑都有一个对应 T，F，$\overline v : \overline S \rightarrow \{T, F\}$ 进行扩展以后即每个合式公式会有有一个对应的 T，F 。我们可以证明对于这种定义，任意一个真值指派下的 $\overline v$ 都是唯一确定。这样通过递归定义的方式,我们就描述清除了合式公式所表达的逻辑关系.

一个公式为真的真值指派下第二个合式公式也一定为真，即为重言蕴涵。当无条件为真的时候即得到了重言式

紧致性定理：对于一个合式公式的无限集合，对于其中的任意一个子集，都存在一个真值指派能够满足其中所有的合式公式。

归纳与递归

我们考虑一个初始集合 B ⊆ U 以及两个函数 f : U × U → U, g : U → U 我们希望描述一种由B中元素任意经过 f 和 g 运算得到的集合 C 的方法

对于构造出来的 C 我们有两种定义方式

自上而下：对于 U 的所有归纳子集(对于f和g是封闭的且包含B)的交集。（取交集是因为可能存在额外元素例如 a）

自下而上： B 中所有的元素有限次使用 f 和 g 得到的元素的集合。这其实就是构造序列的思想

上述的两种定义方式是等价的C*一定是一个包含 B 的归纳子集,C* ⊆ C*

而对于 C* 中的每一个序列  < x0, ...xn> ,对于 xi 递归证明即可, 既然 xi 属于 C* ,那么说所有归纳子集中都包含一个 xi, 又因为这些归纳子集都是封闭的,那么 xi + 1 也都在其中,即取交集以后也在 C* 中,C* ⊆ C*

我们还使用递归的方式进行定义一个函数, 即我们只需要定义基础元素集合 B 中的映射，就能依次扩展到整个 S 上的定义，这样的定义方式为递归的计为 $\overline h$

我们需要指定基础元如何映射

$x \in B, \overline h(x)$

复合元如何映射

$\overline h(x), \overline h(y)$ 计算得到 $\overline h(f(x,y))$

$\overline h(x)$, 计算得到 $\overline h(g(x))$

但是这样的递归形式时可能出现冲突的，可能存在 g(x) = f(x, y) 的情况，这时候我们就不知道应该运用哪一个法则了, 这种情况我们引入自由生成的概念

上述 C 是由 B 在 g 和 f 上是自由生成的必须满足 fc 和 gc 是一对一的，且二者的值域和集合 B 是两两不相交的。可以看出首先是单射，其次是两种不同的运算之间不相交互，这样就排除了上述的冲突，我们得到了一个自由生成的 C

由此我们得到了递归定理，即 C 是自由生成的，我们只需要定义基础元素是如何映射的复合元素是如何映射的, 所得到的递归函数就一定是唯一的。即 h 总能唯一扩展到 $\overline h$ (但这作为证明依然不充分, 详细证明todo())

由递归定理我们可以得到唯一可读定理，我们只需要证明 C 是自由生成的即可。以合式公式为例子，一一对应和两两不相交都是显然的，因为合式公式是自由生成的，其递归定义也是唯一的。

命题联结词

对于布尔函数可以找到一个合式公式 a 使得 a 实现此函数 。这个构造方法比较简单，针对每一个为 T 的取值以一列举然后全部取并。但是这个定理是单项的，a 并不唯一，我们可以找到一种唯一的形式把这种形式称之为DNF，析取范式。

对于任意一个布尔函数，如果可以用连接词集合 S 表达，则称之为S是完备的

值得注意的是 {−, ∨ }, {−, ∧ } 都是完备的。有德摩根定律。{|, ↓ } 也是完备的，可以借用上面的已经得到完备性的结论

紧致性和能行性

紧致性的证明比较有意思，可以对待证明的集合 ∑ 其进行扩展为 Δ，考察所有的合式公式 a，若加入（取并）以后依然有限可满足，则保持 a 不变加入，否则加入  − a, 这样我们总能保证得到的合式公式是有限可满足的。显然此时 ∑ ⊆ Δ 此时我们发现只要对于所有的命题 A，A = T， iff， A ∈ Δ, 就可以使得 Δ 中所有式子都能够满足。

这个真值指派 v 的可行性可以使用归纳法证明。归纳即设对于 a ∈ Δ, v 可以满足 a 为 T 否则则为 F

基础情况是显而易见的。

对于  − b 这样一个合式，其要想为真当且仅当 b 为假，此时我们在构造过程中可以保证 b 一定不在 Δ 中，在此真值指派下 b 一定为假

对于 a ∧ b 这样的合式也是一样，如果其属于 Δ 那说明其一定满足有限可满足

但是我们并不知道 a，b是否在 Δ 中，对于 a，b 如果存在一个不在，则对应的  − a　一定在此时所有真值指派都不能使得 { − a, a ∧ b} 可满足，所以此情况一定不存在。说明 a，b 一定都在其中，那由归纳假设可得 a ∧ b 在 v 上可满足

一阶语言

上面的小节我们对于命题以及命题逻辑有了初步的描述,但是命题内部呢? 我们需要一种对于语言“结构”的更加细节的描述

首先是命题这个概念,即命题联结符作用的对象内部的结构,由此我们定义了项

项的集合是指由常数符号和变量通过使用0次和多次运算 Ff 得到的表达式的集合

Ff(ϵ1, ϵ2, ...) = fϵ1ϵ2...

这里 F 表示函数， f 表示函数对应的符号，这里使用波兰记法，这样的记法是为一可翻译的

原子公式的形式也类似为

Pt1t2...， 从形式上来看和函数非常相似，其中 P 是谓词符号

既然二者如此相似为什么还要分开定义呢？

因为我们之所以要定义这么多符号，最终都要实现一个翻译的功能，即映射到真实世界的对象以及真假之中，否则这些表示式只是单纯的符号集合罢了。 f 以及其最后作用得到的项是为了在结构上对应论域里的对象，而 P 作用后得到的原子公式对应的是真假，即对应的一个“命题”

又引入了命题联结词表示“逻辑”

合式公式是原子公式通过0此或者多次使用 ϵ¬, ϵ→ 和 Qi(i = 1, 2, ...) 运算构成的表达式集合

ϵ¬(a) = (¬a), ϵ→(a, b) = (a → b), Qi(a) = ∀via

当然上述定义都是基于形式语言本身（即表达式的），倒不如说是我们根据现实事物设计了具有这样结构的语言，再验证这样的结构能够真实反映现实事物

¬v3 不是和合式公式，因为 v3 不是原子公式（是项但是没有谓词所以不是原子公式）

基于上述结构我们发现存在一些合式公式中会有变量是“自由”的，其可以由递归的方式定义，显然如果一个合式公式中没有“自由变量”我们无需考虑翻译的时候变量到底选取什么(自由变量需要指定对应的论域中的元素,但是非自由的不需要,其应该为任意的, 因为此时这个变量只是一个代词it)

¬∀v¬ 替换 ∃v 是常用的化简方式

形式语言到真实世界

如上所述我们需要一个“结构”来指明形式语言本身与真实世界的桥梁——即一阶语言的结构 𝔄 (具体参考教材)

注意教材中的 P 是用关系来定义的，当然其实也可以由函数定义（关系集合的有无其实也是一个值域truefalse的函数）

不过事实上我们一直在使用这个“隐藏”的知识，只是现在我们我们开始研究它了。

于是我们给出了递归的定义，一个形式化的语言如何通过这个“结构”一步一步翻译成自然语言

注意，这个结构 𝔄 是不包含各个变量与论域中的东西是如何对应的

对于每一个句子（没有自由变量）那么每个 V 到 |𝔄| 的 s 都能满足，要么每一个都不满足。这个也是显然的，因为没有自由变量意味着所有的变量其实都充当一个代词it的作用，我们实际上需要考虑任意变量到论域的映射

逻辑蕴涵

我们之前提到了重言蕴涵的定义，现在我们对其进行一个扩展，扩展到一阶语言中，定义为逻辑蕴涵

逻辑蕴涵需要保证满足前者的结构和论域映射 s 也满足后者.(这里复习一下满足的定义，即通过结构 𝔄 和 s, 翻译出来的内容是恒真的)

∀v1Qv1 ⊨ Qv2 真

$Q v_1 \not\models \forall v_1 Q v_1$ 假，因为前者是自由变量，后者则不是

 ⊨ ¬¬σ → σ 满足前者的结构和映射，这里会有考虑到 ¬ 的定义是什么？ ¬ 显然是一个逻辑符号，本质是一个符号，我们以此定义了合式公式，但是这个符号在结构中映射是什么呢？ 其实这在之前就由所定义 ⊨𝔄¬Φ[s] 当且仅当 $\not\models_\mathfrak{A} \neg \Phi[s]$, 从这里就可以看出，关于逻辑连接符的满足的定义是模型无关的。我们正在使用一些独立于论域的更加“基础”的知识————即逻辑。这样我们证明了形式语言上的双重否定（其实这是很显然的因为否定符号 ¬ 关于满足的定义就是逻辑上的）

∀v1Qv1 ⊨ ∃v2Qv2 任何结构的域都是非空的

可定义性

一个论域内的元素之间的关系是纷繁复杂的，我们这里想知道到底哪些关系是可使用语言定义的。这里的可定义时说我们通过一个合式公式,指定 n 个自由变量, 当满足此合式公式时候,这些自由变量取值的集合即为我们想要定义的东西

我们发现可以构建一个 ϕ 其中由自由变量 a1, ..., ak ，我们认为  ⊨ ϕ[a1, ..., ak] 则实际表示的关系中存在  < a1, ..., ak>

于是问题就变成了看能不能找到一个 ϕ

但是要说明一个东西是不可定义的是困难的，最直接的可以穷举然后将多个 ϕ 拼接， 因此一般证明这个关系集合是不可数的，但是仅仅有可数个可定义的的公式

现在我们希望能够反过来，如果我们知道一个句子集合 ∑ 我们希望表达到底哪些模型能够“适合”这个句子，我们将其计为 Mod∑, 我们称其为语言的结构类，据此我们定义了初等类合广义初等类。

注意适合即满足，因为我们研究的是句子集，因此也不存在自由变量的问题，不需要函数 s 即可验证公式的真假

对于同态，我们有

演绎

选取一个公式集合以及公理集,能通过逻辑推理推出的所有公式的集合叫做其定理

这里的逻辑推理我们使用假言推理,即若 a 真, a → b 真,则可以得到 b

因此演绎实际上就是一个公式序列,其中任意一个公式都可以由之前的两个公式通过假言推理得到

根据归纳原理,如果 S 是包含 Γ ∪ ∧ 的公式的集合,并且是在假言推理下是封闭的,那么 S 包含 Γ 的所有定理,这个很显然,因为合式公式的构造就包含了假言推理

我们定义概化 Φ = ∀x1...xnψ 为概化,注意概化只是一个形式上的变化

我们接下来研究逻辑公理,将其分为如下所有形式的概化

  1. 重言式

这里的重言式(由于命题逻辑只知道 ¬ 和 →) 如果我们把其中的命题逻辑A,B使用一阶语言的合式公式替换,就能得到重演式的所有公理

基本公式是原子公式和形式为 ∀xα (概化)

非基本, 通过 ¬ 和 → 连接

事实上这样看也能构成所有的合式公式(注意, 合式公式可不都是命题逻辑的形式)

  1. ∀xα → αtx 其中 t 是 x 在 α 中的替换(这里替换的定义要注意)

替换的意思是将 α 中的所有的变量 x 替换为 t 所得到的表达式,对于复合的情况

(¬a)tx = (¬atx)

(a → b)tx = (atx → btx)

(∀ya)tx = ∀ya if x = y

(∀ya)tx = ∀y(atx) if $x \not= y$

但是这样的任意的替换显然不是在所有场合下都是一个公理的, 因为我们是基于符号在操作,如果替换的像项 t 引入了符号 y ,而 y 在原先的符号中又受到量词约束呢? 我们需要定义到底什么情况下这个式子才是可替换的,才能够变成一个逻辑公理

对于原子公式,因为没有量词,所以一定可以替换x

对于¬和→的情况主要看内部的α和β

∀yα 中 t 可以替换 x 当且仅当 要么 x 在 ∀yα 中不是自由出现的 或者 y 在 t 中不出现且 α 中 t 可以替换 x

首先不是自由出现这个很显然,应为本质就是一个it的作用,那么此时无论替换成什么都可以被替换的内容本来就受到了限制(相当于要求变高了), 但是如果是自由变量,那么就要考虑一个问题, 将 x 替换以后会不会约束增多,那么既要其约束 y 在 t 中不出现

即上述公理(2)成立, 任意形式的公式, 可以直接推出任意后的内容(附加替换),只要后面的内容允许替换即可(主要看 x 和要替换的 t 会不会导致一些任意条件的失效)

  1. ∀x(α → β) → (∀xα → ∀xβ)

因为对于任意的 x 的取值, α 成立的时候都有 β 成立, 所以如果任意的 x 情况下 a 都成立, 那么任意的 x 下 β 都成立, 反过来是不成立的, 因为 x 完全可能不是同一个 x

  1. α → ∀xα 且x 在 α 中不是自由出现的, 因为自由->不自由后取值范围变宽了(有点反直觉)

  2. x = x

  3. x = y → (α → α′) 其中 α 是原子的且 α′ 有限的将 α 中的 x 替换为 y 得到的

Γ ⊢ ϕ 当且仅当 Γ ∪ ∧ 重言蕴涵 ϕ

如果可以演绎出来, 那么对于任意真值指派, 可以通过构造序列以及假言推断得到最终的 ϕ 也为真.归纳法, 初始条件一定重言蕴涵自身, 如果 β 是演绎得到的, 则其一定由 α, α → β 得到, 二者均是之前演绎的结果且重演蕴涵后者, 在此演绎链条上对于任意真值指派,只要其使得Γ满足,则一定可以通过链条一直归纳到最终ϕ为真

如果反过来重演蕴涵,则由紧致性定理, 一定有一个有限集合 {γ1, ..., λ1} 重言蕴涵 ϕ

直接将其串联在一起,用 → 连接, γ1, ..., →,λn  → ϕ

显然这个是符合演绎推理的, 这个式子是重言的,依次用假言推理即可

注意逻辑蕴涵和重言蕴涵是不一样的, 后者和前者关注的符号不一样一个例子是 ∀xPx 逻辑蕴涵 Pc, 但是不是重言蕴涵,因为重言的角度认为这完全是两个不同的符号. 之前关于重言式的定义中我们已经发现, 一阶公式本身也是逻辑命题的合式公式(因为全称量词命题逻辑理解不了), 因此如果重言蕴涵 ϕ (此时命题逻辑连接符连接的符号是一个整体A,B), 因为逻辑蕴涵证明的过程中满足Γ的最后一步就是通过命题逻辑检验(此时又重言蕴涵可以直接得到ϕ自然就逻辑蕴涵了), 但是反过来, 合式公式不一定都是命题逻辑的形式,很可能根本就没有命题逻辑连接符的步骤,此时仅仅满足逻辑蕴涵是不能导出重言蕴涵的

我们发现一些“元定理”,即只通过 ∧ 得到的定理

例如  ⊢ Px → ∃yPy

如何将其拆解成一个树呢? 首先我们将后面一部分转化为全称量词的形式

Px → ¬∀y¬Py 我们需要的正是这个式子

我们去掉取反符号,

∀y¬Py → ¬Px (这实际上是一个等价的恒真的推出式) 那么接下来我们再观察这个式子, 其实就是公理2

反过来就得到了树

概化定理: 如果 Γ ⊢ ϕ 且 x 不在 Γ 的任何公式中自由出现, 那么 Γ ⊢ ∀xϕ

直觉上无疑是对的, 如果 x 在 Γ 中不是自由出现那么多加一个任意不会造成扩大

如果本身就在初始公式中,由于不是自由变量,因此加任意是合理的

如果是在逻辑公理中,也是合理的(因为公理恒真)

如果是推理得到的, ψ, ψ → ϕ, 由归纳假设  ⊢ ∀xψ,  ⊢ ∀x(ψ → ϕ)

有恒真式 ∀x(ψ → ϕ) → (∀xψ → ∀xϕ) 继续演绎即可得到 $x x $, 最后得证

但是如果是自由出现的就有问题了, 因此相当于自由变量变为不自由的了, 之前的一个例子 $Px \not= \forall x Px$

其实合概化公理很像,但是这里x不在Γ中合x不在ϕ是一样的

概化定理说明了一个公理可以任意地添加全称量词, 即使这个公里里面含有自由的x, 但是其Γ中的没有x的, 这一点和公理有所区别

规则T是,由定理重言蕴涵的公式b b也是定理, 事实上可以可以反映出一些东西,即重言蕴涵这一概念不涉及公理集合而演绎过程涉及,但是重言蕴涵的判断过程其实已经用到了这些共理的知识, 这就是为什么我们在演绎符号的设计的时候也去掉了 ∧

演绎定理 如果 Γ; γ ⊢ ϕ, 那么 Γ ⊢ (γ → ϕ)

这个证明一方面可以通过重言蕴涵来解决, 我们之前已经证明重言蕴涵和定理之间的关系

这里的关键是 (Γ; γ) ∪  ∧  ⊨ ϕ, Γ ∪  ∧  ⊨ (γ → ϕ)

或者我们直接构建一个具体的演绎

Γ; ϕ ⊢ ¬ψ, iff Γ; ψ ⊢ ¬ϕ

我们有逆否规则(此处不赘述证明)

我定义一个公式集合是不和谐的当且仅当对于某一个公式b,  − b 都是这个公式的定理, 此时对于任意公式a都是此集合的定理, 应为 b →  − b → a 是重言式 (不和谐不等于不能推出)

Γ; ϕ 是不和谐的,那么Γ ⊢ ¬ϕ

一些策略

如果ϕ是推出式, 可以用演绎定理

如果ϕ是全称式,可以考虑概化公理

如果ϕ是否定, 使用规则T

对于常数的情况,我们有常数的概化,若 Γ ⊢ ϕ, c 是不在 Γ 中出现的常数符号, 则对于不出现在 ϕ 中的符号 y ,有 Γ ⊢ ∀yϕyc, 另外存在 Γ 到 ∀yϕyc的演绎,此演绎中不出现 c

若 Γ ⊢ ϕcx 其中常数符号 c 不再 Γ 或者不在 ϕ 中出现,那么Γ ⊢ ∀xϕ, 并且存在从Γ 到 ∀xϕ 的演绎 Γ 中不出现 c

EI规则,即存在规则, 如果 c 不在 ϕ, ψ, Γ 中出现, if Γ; ϕcx ⊢ ψ then Γ; ∃xϕ ⊢ ψ 这是一个存在的说法, c不在任意三者之间是合理的,应为不能引入新的约束
