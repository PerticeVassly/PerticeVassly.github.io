(基本就是复制)

助词

表示主题

は表示说话的主题

当我们发现需要引入新的主题但是主题的内容又和上面一句话的内容相同的时候我们使用も表示也的意思

表示识别

当我们需要提出一个主题的时候但是我们又无法具体指明这个主题的时候我们が取代は来标识这个主题

另外一种情况是用于回答上一个问题，此时我们回答的主题实际上仍然是问题中的那个主题，因此依然是一个无法具体指明的主题，也使用が

或者也可以这样理解，无法指明的主题其实不算是一个新的主题，而は总是带来一个新的主题

表示直接对象

を，日语中句子是以动词作为最基本的元素的，日语使用を表示这个动作作用的直接对象，此时读作o

其中する表示做当前出现　名を＋する　的时候我们可以直接省略を，此时你就可以把　名词＋する　看成一个动词

表示目标

使用に表示动作的目标/方向，这里的目标/方向是一个模糊的概念，时间位置也算

表示方向

へ表示方向，读作e，に表示最终的目标和期望，而へ表示一种大致非最终的阶段性的方向

表示上下文

で表示上下文，意思类似于通过，借助，在

有两个何で，一个表示为什么一个表示借助什么

表示同时成为主题

有时候动作发生的地点也是句子的主题，这种情况下可以把主题助词は」和も加在三个可以指代地点的助词（に、へ、で）后面

直接对象可以不使用を就成为主题。

表示和

と把两个以上的名词连起来,之间的关系是“和”

另一种用法是类似で,表示和某人做了某事

や　とか也表示和的意思,但是其暗示还有很多没有列出来的内容

表示的

对于一个本就有の修饰的名词,在上下文充足的情况下也可以而省略の

の可以用于替代名词, 其类似于こと, 通过在动词和形容词后加入の来表示名词, 但是注意只是替换名词, な形容词的な还是要保留的, 此外你不能把句子的重心(主题)替换成の

の还可以放在句子的结尾表示一种解释的语气, 但是在日语中,男人使用这种语气是不合适的, 一般要在最后加一个だ表示陈述. 如果既要表示状态又要表示解释,此时需要再加一个な变成なの, 但是这个时候读起来的时候のだ很难发音,我们往往会使用んだ取代のだ,变成なんだ

此时这个なんだ变成了和だ一样的一个新的标状态的词,其也有活用形态

按照理论来说这样的表示本质还是再用だ在最后表示状态,所以其完全和之前提到的だ的活用是一样的

表示结束句子

ね　表示赞同

よ 结尾表示想让对方知道这个新的消息

上述两个词语也可以合在一起使用

表示提问

可以在句子末尾加一个か表示提问

但是更多的时候か其实是表示对于某一事情的不确定

当か在关系从句末尾的时候就构成了句子内的一个迷你问题

誰か 谁

何か 什么

いつか　何时

どこか 何处

どれか 哪一个

上述词语中的か改成も可以表示全部否定

将か改为でも可以表示任意的意思

连词

表示因果

使用から链接两个句子表示 原因-结果， 如果原因是字典形名词或者な形容词，后面必须加上だ来现实表达其是原因

丁宁语后应该变为からです

可以根据上下文省略原因和结果，但是省略原因的时候要加上だ

ので和上述から基本可以互换

表示尽管

使用のに表示尽管

表示转折

使用が和けど表示转折（还有けれど）

相对来说这种转折的方式更加礼貌委婉，一般来说が会跟在ます和です的后面

当然也不一定要是非常严格意义上的转折，引出新的话题也可以用这种转折方式

表示如果

表示自然的结果

使用と表示自然的结果

条件 + と + 结果

状态 + だと + 结果

このボタンを押すとドア開きます

静かだとよく眠れます

表示前提条件

使用なら(ば)表示如果(前提)…就…

学生ならこの割引を使えます

由于是表示假设前提, 前提不能使用だ的陈述语气

表示一般条件

使用ば表示一般的条件

  • 对动词(非过去, 非未然) 把最后假名从u段改为同行e段，再加ば

  • 对い形容词以及ない结尾的(未然形)：把最后的换成い换成ければ。

  • 对名词和な形容词加であれば

过去形条件语

首先把名词、形容词或动词活用为过去形，再加上ら

由于过去形都是以だ和た结尾,所以看上去就是だら / たら

たらば / だらば也可以表示, 只是相对没有这么正式

由于条件“已经”发生了,所以这种表达方式主要关注的是结果(这也就是这一小节标题没有写“表示过去条件”)

过去形条件语是唯一可以用过去形结果的用法, 此时这种表达方式已经几乎没有“表示条件”的意思了

もし

もし也表示如果假设, 但是其主要是作为一个提示和示意的作用,用于强调这是一种假设情况,如果就的结构主要还是由上面的几种表达方式完成的

更好的修饰

副词修饰

な形容词 后面加に

い形容词 将い改为く

活用修饰

名词的未然形,过去形,过去未然形可以像形容词一样直接修饰名词, 但是だ的原型形不可以

动词的原形,未然形,过去形,过去未然形可以像形容词一样直接修饰名词

名词本身可以和名词并列表示修饰

名词的だ形,不可以直接修饰名词

从句修饰

动词是句子的构成基本元素,我们可以将一个句子作为一个从句修饰一个名词

表示多种原因

如果你想用多个状态或者动作来表示原因，可以在每个关系从句后面加上し

表示多个动作或者状态

たりする

将动词活用为过去形并且加り,然后在最后一个动词结尾加上する

对于状态表示与也要活用成过去形加上り然后在最后一个动词结尾加上する

使用关系从句作为宾语

直接引用

日语在引用结尾加“と”表示引用

转述引用

思う / 考える表达你在考虑某事

更加简短的引用

と可以转为更加简短的って

多个形容词和名词的串联

对于名词和な形容词后面加上で

对于い形容词，未然形名词或形容词 把い换成くて

多个动词的串联

肯定形式下 把动词换成て形（把动词活用成过去形然后把た换成て,だ换成で）(这里的过去形也包含丁宁语形式的过去时)

未然形式下 把い换成くて（因为都是ない结尾）

更好的表达

表示结果

首先把动词活用为て形，然后加上ある表示结果, 某事情已经处于完成的状态以及为某一件事情做好了准备

表示为未来做准备

首先把动词活用为て形，然后加上おく表示结果，申明某一个动作已经完成（或者将要完成）并且为未来做好了准备

表示动作进行时

首先把动词活用为て形，然后加上いる，得到的新单词可以作为る动词使用, (未然/过去形态参考る动词)

动作动词（行っている / 来ている）的ている」形更像是完成了动作，然后处于某一个个状态

表示动作方向

ていく　てくる　分别表示动作的来和去

表示可能

る动词

把る替换为られる

う动词

最后的假名从u换成同行e再加上る

する できる

くる　こられ

得到的新的动词全部都是る动词

可能形动词由于实际动作没有发生所以不能使用对象助词を

如果想说某物可能存在，你可以把ある和动词 得る 组合起来得到 あり得る，

表示接受

あげる　站在说话人角度的给, 如果表示想要为某人做某事, 可以使用て动词加あげる

如果是第三者使用这个动词, 那么说话者是站在付出的一方的角度上的

如果给的对象是动物宠物, 可以使用やる

くれる 是 あげる 的相反, 表示接受别人的动作(给)

もらう的意思是接受， 字面意思上的接受

之前已经说过 くれる 可以用在疑问句中, 因此可以使用くれる表示一种询问, 我是否可以受到…的帮忙

可以使用未然形让语气变得温柔

要想让别人别做什么，你只要把で加到东西未然形后面就可以了。

表示必须做, 必不能做, 不必做

表示必不能做的事 mustn’t

だめ　行けない　ならない

将动词活用成て形然后加上は再加上以上三个词语

授業中に話してはだめです

表示必须做的事 must

日语使用双重未然来表示必须因此还是使用如下词

だめ　行けない　ならない

  • 将动词未然形活用成て形然后加上は再加上以上三个词

  • 动词未然形 + 表示条件的と + 以上三个词

  • 动词未然形 + 表示条件的ば + 以上三个词

后两种实际上是一种条件表达, 如果没做, 就会发生不好的事情

当然也可以简写把上面后两种表达中的一些固定短语替换掉

  • 把なくて换成なくちゃ

  • 把なければ换成なきゃ

然后就不需要说后面的三个表示否定的词了

对于ては　/　では　可以分别替换为ちゃ / じゃ, 但是这样最后的三个词就不能省略了

表示不必做的事 mustn’t

把て形加上助词も表达, 即使做了什么，后面跟いい、大丈夫或構わない

表示希望和建议

表示想要做

将动词转化为たい形, 将其视为一个い形容词, 同时由于是动词, 因此也具有动词的属性

在非提问句子中你不能这样使用, 因为你无法断定别人心里的在想什么

表示想要的东西, 或者想要完成的事情

使用 欲しい　表示其是一个い形容词

使用意向形来提议做某事

将动词活用成意向形

使用体检语句的方式来

你可以用条件语ば或たら提意见，后面再加上どう

表示做出请求

くれる 的敬语版本是 くださる

くださる 的特殊活用形是 ください

くれる 在疑问句中使用

ください 表示直接请求, 可以将其加在动词的て形后

日语中会直接去掉ください以动词て形结尾

ください的替代词是ちょうだい, 语法上和ください一样

なさい 表示做出礼貌而坚决的请求

なさい是する的一种特别的敬语活用形,使用方法为把动词活用为词根，再加上なさい

除此以外可以使用命令形和否定命令形来表示请求

表示定义和描述

使用という来定义和识别任何东西

当一个关系从句被と引用以后, 必须使用一个动词来配合它, 此时我们可以使用いう

我们可以把提问词か加到という后面来提问。这种结构用在你想改述或重定义什么东西的时候

って可以替代という

だって可以看成上述规则的进一步简写, 意思是即使是那样

实际说话过程中, 会有ゆう替代いう

表示试和尝试

动词活用成て形加上みる表示尝试

将动词或用成意向形然后引用(と)然后加上する, 当然使用決める也可以
