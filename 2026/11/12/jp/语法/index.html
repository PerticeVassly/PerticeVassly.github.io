基本语法

参考资料：

https://riyutool.com/jpgrammar/stateofbeing.html

标日

(基本就是复制)

形容词

基本分类

な形容词

修饰名词必须在名词之前加上 な

静かな街道

い形容词

い形容词都是以い结尾，注意有一些词语是汉字最后的发音为い，这种不算以い结尾，但是确实有一些以い结尾的是な形容词。

美しい花

动词

基本分类

る动词

一定以る结尾

う动词

其他u元音字结尾或者以る结尾且前面是a、u、o音节

可见所有的动词（除了特例）都是u行字结尾

存在两个特例动词 する / くる 分别表示做和来

动词还分为他动词和自动词,这个含义就是字面意义上的含义

自动词和他动词

自动词不能带直接对象, 相当于英语里面没有宾语, 唯一可以和自动词合用助词を的情况是地点是动作动词的直接对象

词根

る动词 把る去掉

う动词 把最后的假名从う段换成同行い段

する し

くる き

活用

日语通过活用的形式表示过去以及未然等众多形式

形容词（以及名词）

名词和な形容词

可以把如下的词加到名词或者是な形容词后面（い形容词不可以这样使用）。

使用だ / だった表示事物当前/未来的状态，对于当前/未来且非未然的情况只有一个だ，可以直接省略这个だ

使用じゃない / じゃなかった表示事物过去的状态

原形

静か（だ）　学生（だ）

原形未然

静かじゃない　学生じゃない

过去

静かだった　学生だった

过去未然

静かじゃなかった　学生じゃなかった

い形容词

可以把如下的词加到い形容词后面

い形容词可以直接表示现在/未来的状态（不要加だ），い变为くない，表示未然

使用い变为かった/い变为くなかった表示事物过去的状态

いい是好的意思，实际上由よい演变过来，所以应该按照后者的标准活用

原形

　美しい

原形未然

　美しくない

过去

　美しかった

过去未然

　美しくなかった

动词

る动词

未然形态为把る替换为ない

其过去式为把る改为た

过去未然因为是ない结尾所以将ない变为なかった

原型

　食べる

未然

　食べない

过去

　食べた

过去未然

　食べなかった

う动词

规则比较复杂

未然：

以う结尾的动词，未然将う换成わない（这里其实因为这里的う其实是わ行的う而不是元音的う）

对于其他う动词把最后一个假名换成换成同行的あ段假名再加上ない

过去：

う动词则根据末尾假名分为四类

す，去掉す改为した

く / ぐ，分别去掉く / ぐ加上いた / いだ

む / ぶ / ぬ，分别去掉む / ぶ / ぬ加上んだ

る / う / つ，分别去掉る / う / つ加上った

过去未然：

未然形态都是ない结尾所以，依旧遵循ない换成なかった的规则

词尾 原形 未然 过去 过去未然
す 話す 話さない 話した 話さなかった
く 書く 書かない 書いた 書かなかった
ぐ 泳ぐ 泳がない 泳いだ 泳がなかった
む 読む 読まない 読んだ 読まなかった
ぶ 遊ぶ 遊ばない 遊んだ 遊ばなかった
ぬ 死ぬ 死なない 死んだ しななかった
る 取る 取らない 取った とらなかった
う 買う 買わない 買った 買わなかった
つ 待つ 待たない 待った 待たなかった

ある是一个特例，其未然为ない（过去 なった，过去未然 なかった）

行く是一个特例，其过去未行った（未然 行かない　过去未然 いかなかった）

特殊动词

する　未然 しない 过去 した 过去未然 しなかった

くる　未然 こない 过去 きた　过去未然　こなかった

动词的で形态

把动词活用成过去形然后把其中的た换成て,だ换成で

助词

助词用于构建一个句子的基本结构

表示主题

は表示说话的主题

当我们发现需要引入新的主题但是主题的内容又和上面一句话的内容相同的时候我们使用も表示也的意思

表示识别

当我们需要提出一个主题的时候但是我们又无法具体指明这个主题的时候我们が取代は来标识这个主题

另外一种情况是用于回答上一个问题，此时我们回答的主题实际上仍然是问题中的那个主题，因此依然是一个无法具体指明的主题，也使用が

或者也可以这样理解，无法指明的主题其实不算是一个新的主题，而は总是带来一个新的主题

表示直接对象

を，日语中句子是以动词作为最基本的元素的，日语使用を表示这个动作作用的直接对象，此时读作o

其中する表示做当前出现　名を＋する　的时候我们可以直接省略を，此时你就可以把　名词＋する　看成一个动词

表示目标

使用に表示动作的目标/方向，这里的目标/方向是一个模糊的概念，时间位置也算

表示方向

へ表示方向，读作e，に表示最终的目标和期望，而へ表示一种大致非最终的阶段性的方向

表示上下文

で表示上下文，意思类似于通过，借助，在

有两个何で，一个表示为什么一个表示借助什么

表示同时成为主题

有时候动作发生的地点也是句子的主题，这种情况下可以把主题助词は」和も加在三个可以指代地点的助词（に、へ、で）后面

直接对象可以不使用を就成为主题。

表示和

と把两个以上的名词连起来,之间的关系是“和”

另一种用法是类似で,表示和某人做了某事

や　とか也表示和的意思,但是其暗示还有很多没有列出来的内容

表示的

对于一个本就有の修饰的名词,在上下文充足的情况下也可以而省略の

の可以用于替代名词, 其类似于こと, 通过在动词和形容词后加入の来表示名词, 但是注意只是替换名词, な形容词的な还是要保留的, 此外你不能把句子的重心(主题)替换成の

の还可以放在句子的结尾表示一种解释的语气, 但是在日语中,男人使用这种语气是不合适的, 一般要在最后加一个だ表示陈述. 如果既要表示状态又要表示解释,此时需要再加一个な变成なの, 但是这个时候读起来的时候のだ很难发音,我们往往会使用んだ取代のだ,变成なんだ

此时这个なんだ变成了和だ一样的一个新的标状态的词,其也有活用形态

按照理论来说这样的表示本质还是再用だ在最后表示状态,所以其完全和之前提到的だ的活用是一样的

表示结束句子

ね　表示赞同

よ 结尾表示想让对方知道这个新的消息

上述两个词语也可以合在一起使用

表示提问

可以在句子末尾加一个か表示提问

但是更多的时候か其实是表示对于某一事情的不确定

当か在关系从句末尾的时候就构成了句子内的一个迷你问题

誰か 谁

何か 什么

いつか　何时

どこか 何处

どれか 哪一个

上述词语中的か改成も可以表示全部否定

将か改为でも可以表示任意的意思

连词

表示因果

使用から链接两个句子表示 原因-结果， 如果原因是字典形名词或者な形容词，后面必须加上だ来现实表达其是原因

丁宁语后应该变为からです

可以根据上下文省略原因和结果，但是省略原因的时候要加上だ

ので和上述から基本可以互换

表示尽管

使用のに表示尽管

表示转折

使用が和けど表示转折（还有けれど）

相对来说这种转折的方式更加礼貌委婉，一般来说が会跟在ます和です的后面

当然也不一定要是非常严格意义上的转折，引出新的话题也可以用这种转折方式

更好的修饰

副词修饰

な形容词 后面加に

い形容词 将い改为く

活用修饰

名词的未然,过去时,过去未然可以和形容词一样直接修饰名词

名词本身可以和名词并列表示修饰

名词的だ形,不可以直接修饰名词

从句修饰

动词是句子的构成基本元素,我们可以将一个句子作为一个从句修饰一个名词

表示多种原因

如果你想用多个状态或者动作来表示原因，可以在每个关系从句后面加上し

表示多个动作或者状态

たりする

将动词活用为过去形并且加り,然后在最后一个动词结尾加上する

对于状态表示与也要活用成过去形加上り然后在最后一个动词结尾加上する

多个形容词和名词的串联

对于名词和な形容词后面加上で

对于い形容词，未然形名词或形容词 把い换成くて

多个动词的串联

肯定形式下 把动词换成て形（把动词活用成过去形然后把た换成て,だ换成で）(这里的过去形也包含丁宁语形式的过去时)

未然形式下 把い换成くて（因为都是ない结尾）

更多的动词用法

表示结果

首先把动词活用为て形，然后加上ある表示结果, 某事情已经处于完成的状态以及为某一件事情做好了准备

表示为未来做准备

首先把动词活用为て形，然后加上おく表示结果，申明某一个动作已经完成（或者将要完成）并且为未来做好了准备

表示动作进行时

首先把动词活用为て形，然后加上いる，得到的新单词可以作为る动词使用, (未然/过去形态参考る动词)

动作动词（行っている / 来ている）的ている」形更像是完成了动作，然后处于某一个个状态

表示动作方向

ていく　てくる　分别表示动作的来和去

表示可能

る动词

把る替换为られる

う动词

最后的假名从u换成同行e再加上る

する できる

くる　こられ

得到的新的动词全部都是る动词

可能形动词由于实际动作没有发生所以不能使用对象助词を

如果想说某物可能存在，你可以把ある和动词 得る 组合起来得到 あり得る，
