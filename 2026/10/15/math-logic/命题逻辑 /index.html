命题

我们基于最基本的真假的概念定义了命题。通过对于形式语言进行定义和构造得到了合式公式。

通过真值指派赋予其意义构成了命题逻辑。v : S → {T, F} 即对于每一个命题逻辑都有一个对应 T，F，v̂ : Ŝ → {T, F} 进行扩展以后即每个合式公式会有有一个对应的 T，F 。我们可以证明对于这种定义，任意一个真值指派下的 v̂ 都是唯一确定。

显然一个公式为真的真值指派下第二个合式公式也一定为真，即为重言蕴涵。由此可以得到极端情况重言式

紧致性定理：对于一个合式公式的无限集合，对于其中的任意一个子集，都存在一个真值指派能够满足其中所有的合式公式。

归纳与递归

对于构造出来的 C 我们有两种定义方式

自上而下：对于U的所有归纳子集的交集。（取交集是因为可能存在额外元素例如 a）

自下而上： B 中所有的元素有限次使用 f 和 g 得到的元素的集合。这其实就是构造序列的思想

我们通常使用递归的方式进行定义一个函数, 即我们只需要定义基础元素集合B中的映射，就能依次扩展到整个S上的定义，这样的定义方式为递归的计为 ĥ

我们需要指定基础元如何映射

x ∈ B, ĥ(x)

复合元如何映射

ĥ(x), ĥ(y) 计算得到 ĥ(f(x, y))

ĥ(x), 计算得到 ĥ(g(x))

但是这样的递归形式时可能出现冲突的，可能存在 g(x) = f(x, y) 的情况，这种情况我们引入自由生成的概念

C 是由 B 在 g 和 f 上是自由生成的必须满足 fc 和 gc 是一对一的，且二者的值域和集合 B 是两两不相交的。可以看出首先是单射，其次是两种不同的运算之间不相交互，这样就排除了上述的冲突，我们得到了一个自由生成的 C

由此我们得到了递归定理，即C是自由生成的，我们只需要定义基础元素是如何映射的复合元素是如何映射的, 所得到的递归函数就一定是唯一的。

由递归定理我们可以得到唯一可读定理，我们只需要证明C是自由生成的即可。以合式公式为例子，一一对应和两两不相交都是显然的，因为合式公式是自由生成的，其递归定义也是唯一的。

紧致性和能行性

紧致性的证明比较有意思，可以对待证明的集合 ∑ 其进行扩展为 Δ，考察所有的合式公式 a，若加入（取并）以后依然有限可满足，则保持 a 不变加入，否则加入  − a, 这样我们总能保证得到的合式公式是有限可满足的。显然此时 ∑ ⊆ Δ 此时我们发现只要对于所有的命题 A，A = T，iff，A ∈ Δ, 就可以使得 Δ 中所有式子都能够满足。

这个真值指派 ｖ 的可行性可以使用归纳法证明。归纳即设对于 a ∈ Δ, v 可以满足 a 为 T 否则则为 F

基础情况是显而易见的。

对于  − b 这样一个合式，其要想为真当且仅当 b 为假，此时我们在构造过程中可以保证 b 一定不在 Δ 中，在此真值指派下 b 一定为假

对于 a ∧ b 这样的合式也是一样，如果其属于 Δ 那说明其一定满足有限可满足

一阶语言

我们需要一种对于语言“结构”的更加精准的定义

项的集合是指由常数符号和变量通过使用0次和多次运算 Ff 得到的表达式的集合

Ff(ϵ1, ϵ2, ...) = fϵ1ϵ2...

这里 F 表示函数， f 表示函数对应的符号，这里使用波兰记法，这样的记法是为一可翻译的

原子公式的形式也类似为

Pt1t2...， 从形式上来看和函数非常相似，其中 P 是谓词符号

既然二者如此相似为什么还要分开定义呢？

因为我们之所以要定义这么多符号，最终都要实现一个翻译的功能，即映射到真实世界的对象以及真假之中，否则这些表示式只是单纯的符号集合罢了。 f 以及其最后作用得到的项是为了在结构上对应论域里的对象，而 p 作用后得到的原子公式对应的是真假，即对应的一个“命题”

又引入了命题联结词表示“逻辑”

合式公式是原子公式通过0此或者多次使用 ϵ¬, ϵ→ 和 Qi(i = 1, 2, ...) 运算构成的表达式集合

ϵ¬(a) = (¬a), ϵ→(a, b) = (a → b), Qi(a) = ∀via

当然上述定义都是基于形式语言本身（即表达式的），倒不如说是我们根据现实事物设计了具有这样结构的语言，再验证这样的结构能够真实反映现实事物

¬v3 不是和合式公式，因为 v3 不是原子公式（是项但是没有谓词所以不是原子公式）

基于上述结构我们发现存在一些合式公式中会有变量是“自由”的，其可以由递归的方式定义，显然如果一个合式公式中没有“自由变量”我们无需考虑翻译的时候变量到底选取什么（因为此时这个变量只是一个代词it）

¬∀v¬ 替换 $\exist v$ 是常用的化简方式

注意教材中的P是用关系来定义的，当然其实也可以由函数定义（关系集合的有无其实也是一个值域truefalse的函数）
