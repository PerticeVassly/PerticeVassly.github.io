Design Patterns

Architecture pattern

  • is a package of design decisions that is found repeatedly in practice,

  • has known properties that permit reuse, and describes a class of architectures.

Architecture pattern establishes a relationship between:

  • A context: A recurring, common situation in the world that gives rise to a problem.

  • A problem: The problem, appropriately generalized, that arises in the given context.

  • A solution: A successful architecture resolution to the problem, appropriately abstracted.

Design Concepts

Avoid reinventing the wheel

There are several categories of design concepts, someareabstractand some more concrete.

Reference Architectures : provide a blueprint for structuring an application

  • Mobile applications
  • Rich client applications
  • Rich internet applications
  • Service Applications
  • Web applications

Deployment Patterns : provide guidance on how to structure the system from a physical standpoint

Tactics : Design decisions that influence the control of a quality attribute

Patterns : Patterns are proven (conceptual) solutions to recurring design problems.

Externally developed components : resuable components （framework）

关系梳理

tactic = design decision 针对QA，每个QA都有多个tactic

strategy = 多个tactic组成，一种思想方法/手段

pattern = 多个tactic组成，特定context下为了解决特定problem而设计的solution。

design concepts 包含patterns，tactics，reference architectures等
